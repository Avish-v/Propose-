# Chandhana — Love Confession Website

A responsive, static HTML/CSS/JavaScript website with a black + rose-gold theme.

## Run locally
1. Extract `chandhana-love-confession.zip`.
2. Open the folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Included
- Responsive layout for mobile and desktop
- Three letter tabs: Tanglish, English, and Malayalam English (Manglish)
- Your uploaded memory and artwork photos in `assets/`
- Optional background music toggle
- Respectful, no-pressure closing message

## Add background music
The project does not include a commercial song. If you have permission to use an instrumental MP3, place it in the `assets` folder and name it exactly:

`malayalam-instrumental.mp3`

The music button will then play/pause it. Browsers require a user click before audio can start.

## Publish free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will show the published website URL.

## Replace photos
The current gallery uses the four supplied photos:
- `assets/memory-200.jpg`
- `assets/name-artwork.jpg`
- `assets/handwritten-note.jpg`
- `assets/eye-drawing.jpg`

Replace a file with another photo using the same filename to update the page without changing code.
